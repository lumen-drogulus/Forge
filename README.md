# FORGE

A workout planner and tracker for the PH-PPL program (Power/Hypertrophy Push-Pull-Legs). Runs in Chrome on Android and installs to the home screen like a regular app.

Live at [lumen-drogulus.github.io/Forge](https://lumen-drogulus.github.io/Forge/). This is the main copy: every change lands here first, then goes out to the other copies.

## Where the data lives

On the phone, inside Chrome. Nothing is sent anywhere. Use **Settings → Back up data** to send a copy to Drive, email or a text, and **Restore from backup** to load one. The app reminds you on the Home screen when a backup is overdue.

## Files

| File | What it is |
|---|---|
| `index.html` | The app's page: splash, PR screen, panels |
| `js/config.js` | Whose copy this is. **The only app file that differs between copies.** |
| `js/data.js` | The program. `MOVES` holds each exercise once (name, tip, video); each workout lists moves by id with its own sets, reps, RPE, rest and size tier |
| `js/app.js` | Everything the app does |
| `js/figures.js`, `js/moves.js` | The animated exercise figures. Generated by a build script from the figure source; never hand-edit |
| `css/` | The look (`styles.css`), the figures (`figures.css`) and the icons (`icons.css`) |
| `fonts/` | Barlow Condensed, Barlow and JetBrains Mono, stored here so the app works with no signal |
| `sw.js` | Lets the app work offline and pick up updates. Bump `CACHE_VERSION` on every change |
| `manifest.json`, `*.png` | App name and icons |

To update a copy, copy every file over it **except `js/config.js`, `guide.html` and `README.md`**. Logged workouts are untouched: they live on the phones, not in these files.

All copies share one web address, and the phone keeps one storage box per address. So each phone opens exactly one copy; testing another copy happens in a Chrome guest window.
